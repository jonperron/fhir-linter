ucum-essence.xml
================

Purpose: ucum-essence.xml is an unmodified, byte-identical copy of the
UCUM essence file (version 2.0.1), as distributed in the FHIR test cases
repository (tests/fixtures/ucum/ucum-essence.xml). The fhir-fhirpath
crate embeds it and reads its prefix and unit definitions at runtime to
convert FHIRPath Quantity values between units. The file is not
modified; no table derived from it is distributed.
